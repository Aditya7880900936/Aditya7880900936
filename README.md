## 🌍 Open Source & Systems Work

I actively contribute to **large, production-grade open-source projects**.

My approach to open source:
- Study the architecture before writing code
- Trace requests end-to-end through the system
- Understand invariants, failure modes, and edge cases
- Communicate clearly with maintainers through reviews
- Prefer small, correct changes over large, risky ones

**Areas I’m deeply interested in:**
- Cloud-native networking
- Service meshes and gateways

- Protocols, APIs, and distributed system behavior
- Testing for correctness and determinism
